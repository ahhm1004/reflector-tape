1. native 0줄 + tusk-boot 바이트 유지 [확인]

tusk_native는 완전 정적 aarch64. 보드 기종당 1회 만드는 기반 이미지(Ubuntu 22.04 + Tusk 호환 계층)에 빈 wch.ko와 rpcbind(비활성)만 넣으면 prepare.sh 패치 없이 동작 [추정, 벤치 확정].

2. hard-config 0줄 = IMU 세로 장착 [확인]

칩 −Y축이 하늘(MC-40 동일) + /dev/i2c-2 + can1. HANDOFF 8절의 "평평 장착"은 z_acc≈0으로 D0303 측위 거부 발생(X1 보정).

3. 헬퍼 5종 ELF 전수 통과 [확인]

Ubuntu 22.04 / Debian 12 기본 라이브러리 링크 확인. 필수 3건: /dev/ttysWK0 가짜 PTY, 00-tusk.conf(X6), /home/agvupg-web 복사(X7). 원본 nginx는 libxcrypt 호환 심볼로 실행 유력 [추정·높음].

4. 최대 신규 위험 = 보드 크기 간섭 [추정]

MC-40(≈142×91 mm)은 커넥터를 위로 세워져 배선 다발 사이 폭을 거의 다 차지. 후보 1 OK3588J-C(190×130, 케이스 ≈210×150)는 같은 자리 폭 초과 유력 → 실측 #2 전 발주 금지.

5. 전원 통일안 (48V→IC-40→24V) [확인]

T10은 24V 리튬 직결이 아닌 정전압 24V 레일(X9). 후보 1 = RSD-60G-12 보드 전용(≤33%), 후보 3 = 24V 직결, Mid-360S = 24V+2A 퓨즈 독립 분기(DDR-120 불필요).

6. 통일 BOM (1대, VAT 포함) [확인]

교체 세트: 후보 1 1,390,806원 · 후보 3-B 2,622,606원 · 후보 3-A 2,712,033원. +Mid-360S 국내(+1,600,000) / 해외(+1,358,533). 후보 3-A는 3-B 대비 +89,427원 및 배선 위험으로 비권장.
